今日の日付で daily ノートを作成する。ユーザーに今日やることを対話的に入力してもらい、その内容をテンプレートに反映させる。

## 手順

1. `daily/` ディレクトリに今日の日付（`YYYY-MM-DD.md`）のファイルが既に存在するか確認する。存在する場合は上書きせずにその旨を伝えて終了する。
2. **タスクの入力**（ミーティング以外）: 「今日やるタスクを入力してください（1つずつ）」とテキストで尋ね、ユーザーの返答を待つ。1つ入力されたら「次のタスクはありますか？」と続ける。ユーザーが「終わり」「なし」「以上」「ない」など終了を示す回答をしたら次へ進む。
3. **ミーティングの入力**: 同様に「ミーティングを入力してください（1つずつ）」とテキストで尋ね、同じ流れで入力してもらう。
4. 入力された内容をテンプレートに反映して、ファイルを作成する。

### 入力時のポイント

- 通常の対話メッセージで入力を受け付ける。ユーザーがチャットに直接タスク名やミーティング名を入力する形式。
- 最初のタスクを聞く時点で「なし」「ない」などと答えた場合は、タスク0件として扱う。ミーティングも同様。
- 入力が0件でも問題ない（空のまま進む）

## テンプレート

```
[[前日の日付]] | [[翌日の日付]]

# 今日やること
- {タスク1}
- {タスク2}
- ...
- ミーティング
    - {ミーティング1}
    - {ミーティング2}
    - ...

# 実際にやったこと
-

# 作業メモ
```

- 1行目は前日・翌日へのリンク: `[[YYYY-MM-DD]] | [[YYYY-MM-DD]]`
- タスクが0件の場合は `- ` のみ（ハイフンとスペース）にする
- ミーティングが0件の場合は `- ミーティング` の下に `    -` のみにする
- 「実際にやったこと」「作業メモ」は常に空（`- ` のみ）
